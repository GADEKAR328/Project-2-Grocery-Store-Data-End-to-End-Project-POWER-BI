# Project-2-Grocery-Store-Data-End-to-End-Project-POWER-BI
This repository presents an end-to-end Power BI dashboard project based on grocery store sales data (Swiggy Instamart-inspired). The project focuses on analyzing sales performance, customer behavior, and store-level insights to support data-driven decision-making.

# 🚀 Project Overview

The dashboard provides a complete analysis of food delivery operations, including:

- 📦 15.1K+ Total Quantity delivered across
- 🧾 2.7K+ Transactions
- 📈 Monthly order trends to identify demand patterns
- 🍽️ Category-wise analysis (Main Course, Snacks, Desserts, etc.)
- 👑 Member segmentation (Gold vs Regular customers)
- 🥇 Top-selling food items (Samosa, Butter Chicken, Biryani, etc.)
- 🚚 Delivery status insights (~94% successful deliveries)
- 💳 Payment method analysis (UPI, COD, Card)
- 📅 Year & month-wise performance trends
  # 🛠️ Tools & Technologies Used
    - Power BI – Dashboard creation & visualization
    - Power Query – Data cleaning & transformation
    - DAX – Calculated measures & KPIs
    - Data Modeling – Relationship building
      
# 📊 Key Insights
- Main Course category generates the highest orders
- UPI is the most preferred payment method
- High delivery success rate indicates strong operations
- Certain food items consistently outperform others
- Monthly trends help identify peak demand periods
